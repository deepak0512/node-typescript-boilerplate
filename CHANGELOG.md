# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- `doc-sync` CLI (`npm run doc-sync -- --repo owner/repo --out <file> [--check]`). It fetches core repository metadata from the GitHub REST API: name, full name, description, URL, default branch, license, topics, homepage and created date. It renders them as a Markdown table between `<!-- doc-sync:start -->` and `<!-- doc-sync:end -->` markers in an existing file.
  - Fields GitHub does not provide are shown as `Not Found`.
  - `--check` exits `1` when the document is out of date, which makes it usable as a CI gate.
  - Exit codes are fixed: `0` success, `1` out of date, `2` usage error, `3` API or file error.
  - The optional `GITHUB_TOKEN` is sent only to `https://api.github.com` and is never printed.
  - Writes are atomic, preserve line endings, the BOM and the file mode, and happen only when the data changes.
- `docs/PROJECT_INFO.md`: a sample document generated by `doc-sync`.
- Unit and integration test suites for `doc-sync`, plus a content-quality check of the sample document.
- npm scripts: `doc-sync`, `test:integration`, `test:coverage:all`.
- SDLC documentation in `docs/sdlc/`: user story, requirements, architecture, design review, implementation plan, code review, verification.
- GitHub Copilot customizations that drive each SDLC step:
  - agents in `.github/agents/`;
  - prompts in `.github/prompts/`;
  - path-scoped instructions in `.github/instructions/`;
  - the `verify-doc-sync` skill;
  - hooks that block `.env` access and format edited TypeScript.

### Changed

- CI (`.github/workflows/nodejs.yml`) also runs `npm run test:integration`.
- `README.md` documents `doc-sync` and the new scripts.
- Vitest coverage excludes the process entry point `src/doc-sync/bin.ts`.
